# Freelance Rate Card & Finance Tracker

> **How to use this:** Copy this file into `private/` (e.g. as
> `finances.md`) and fill it with your own numbers. It holds real
> financial data once you do, so it stays in `private/` — which is
> gitignored — and never gets committed. This tracked copy is the blank
> kit: structure and method only, no personal figures.
>
> Prefer a spreadsheet? `freelance-finances-kit.xlsx` sits alongside
> this file with the same structure and live formulas already wired up
> (price = hours × rate, subscription totals, and a quarterly roll-up
> that pulls from the ledger with the tax set-aside). Copy it into
> `private/` before you fill it in, same as this one.
>
> Four parts: a **rate card** for quoting work, a **subscription
> ledger** to watch tool-cost creep, a running **income/expense log**,
> and a **quarterly roll-up** for setting aside tax. None of it is tax
> advice — confirm anything that matters with a professional.

## Rate card

*Pick a base hourly rate. Estimate the minimum hours a project type
realistically takes you (setup, revisions, and handoff included, not
just the making). Project price = min hours × your rate. The point is a
fast, defensible number when someone asks "what would this cost," not a
promise you'll stop at the minimum.*

| Design type | Min hours (est.) | Price |
| :-- | :-: | :-: |
| Presentations, decks | 5 | |
| Emails, broadcast | 5 | |
| Consult | 10 | |
| Print, packaging, production | 15 | |
| Single page / landing-page UI | 50 | |
| Full site UX/UI | 100 | |
| Experiential | 150 | |

- **Open hourly rate:** `$__/hr` *(your negotiable floor for scoped-by-the-hour work)*
- **Full-time conversion:** `$______/yr` *(the salary number you'd convert a client to, if asked)*

*The hour estimates above are starting anchors — adjust them to your own
pace after a few real projects.*
